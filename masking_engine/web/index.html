🛡️ Context-Aware Masking Engine

R26-CS-012 — live demo of the real detection pipeline (regex + rule-based scoring, no simulation)

How the pipeline works
  1. Normalize — URL/hex/Base64 decode, strip adversarial spacing (e.g. 1 9 9 0 1 2 3 → 1990123), classify context type.
  2. Detect — compiled regex patterns + rule-based NER scan the normalized (and despaced) text for candidate entities.
  3. Score — each candidate gets a 0–1 confidence score from 4 weighted factors: pattern match strength (40%), keyword proximity (30%), co-occurrence with other entities (20%), format validity (10%).
  4. Resolve overlaps — where two entity types could both explain the same text (e.g. a 12-digit number could be an NIC or an account number), the higher-scoring candidate wins.
  5. Mask — score decides the action: mask_immediate (≥0.75), mask_warn (≥0.50), log_suspected (≥0.25, not masked), ignore (<0.25).
